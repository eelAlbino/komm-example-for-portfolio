# Ревью кода

## Критические ошибки

- **Выгрузка открытой ветки может захватить файлы из приватных ответов.** Form Request и контроллер проверяют доступ к запрошенному комментарию. Рекурсивный обход собирает вложения дочерних комментариев без проверки политики каждого ответа. Участник проекта с доступом к открытому родительскому комментарию может получить файлы из связанного приватного ответа. Вывод следует из кода. Для демонстрации используйте localhost и синтетические данные. [Модель](../app/Models/Comment.php) · [Политика](../app/Policies/CommentPolicy.php)
- **URL архива доступен в обход политики комментария.** Контроллер возвращает URL Orchid, а локальная конфигурация раздаёт публичный диск через ссылку хранилища Laravel. В этой конфигурации по URL можно скачать архив и после изменения прав участника. Проверена локальная схема раздачи файлов. Правила доступа на исходном сервере лежат за пределами выделения. [Контроллер](../app/Http/Controllers/Api/V1/CommentController.php) · [Хранилище](../config/filesystems.php)

## Существенные замечания

- **Одновременные запросы могут дублировать работу или получать ошибку уникальности.** Сервис читает, удаляет или создаёт запись без блокировки. В MySQL составной уникальный индекс допускает несколько строк с `filter_hash=NULL`. При одинаковом непустом фильтре один из запросов может получить ошибку ограничения. [Сервис](../app/Services/Comments/AttachmentArchiveService.php) · [Миграция](../database/migrations/2024_03_29_081534_create_comment_attachment_archives_table.php)
- **Прогресс записывается раньше содержимого ZIP.** Job удаляет запись об ожидающем файле сразу после `addFile`, а закрывает ZIP позднее. Результаты `addFile` и `close` не проверяются. Пропавший файл, ошибка диска или остановка воркера могут привести к неполному архиву со статусом `filled` либо потере данных о том, что нужно обработать при повторе. Одновременная обработка одного архива двумя заданиями тоже возможна. [Job](../app/Jobs/FillCommentAttachmentArchiveJob.php)
- **Замена и очистка архивов могут оставлять файлы на диске.** При замене устаревшего архива сервис удаляет его запись без удаления полиморфного вложения. Команда очистки выбирает строки со старым `showed_at`. Архив, который ни разу не был выдан, может оставаться в хранилище бессрочно. [Сервис](../app/Services/Comments/AttachmentArchiveService.php) · [Команда очистки](../app/Console/Commands/Comments/DeleteOldAttachmentArchives.php)
- **Глубокие ветки увеличивают число запросов и расход памяти.** Ленивая загрузка ответов и вложений может давать два запроса на каждый комментарий. Сервис собирает вложения до поиска пригодного ZIP и фильтрует их в PHP. Job читает ожидающие файлы по 20 за запрос, а исходный список записывает по одной строке. [Модель](../app/Models/Comment.php) · [Job](../app/Jobs/FillCommentAttachmentArchiveJob.php)

## Допустимый технический долг

- Form Request и контроллер проверяют доступ к одному комментарию, повторяя поиск и проверку членства. [Form Request](../app/Http/Requests/GetFilesZipCommentRequest.php) · [Контроллер](../app/Http/Controllers/Api/V1/CommentController.php)
- Для сравнения архивов используются упорядоченные ID вложений и сериализованные параметры фильтра. Перестановка ID может вызвать пересборку. Изменение содержимого при сохранении ID может остаться незамеченным. [Сервис](../app/Services/Comments/AttachmentArchiveService.php)
- Тесты охватывают доступ к API, повторное использование ZIP, продолжение сборки и очистку. Некоторые тесты сервиса вызывают приватные методы через Reflection. Конкурентные запросы, сбои диска, приватные ответы и большие ветки остаются без покрытия. Ошибка регистра в одном исходном тесте разобрана в отчёте о проверке. [Тесты](../tests) · [Результаты проверки](verification.md)

## Спорные архитектурные решения

- Первый этап сборки выполняется прямо при обработке запроса. Небольшие архивы доступны сразу, а медленный диск или сжатие могут задержать ответ. Бюджет времени ограничивает цикл обработки. Закрытие и сохранение ZIP могут увеличить полное время запроса сверх этого бюджета. [Сервис](../app/Services/Comments/AttachmentArchiveService.php) · [Job](../app/Jobs/FillCommentAttachmentArchiveJob.php)
- SQL-транзакция объединяет создание записи вложения и полиморфной связи. Запись и удаление файлов имеют собственные режимы отказа. HTTP-процессу и воркеру нужен доступ к одной файловой системе, поскольку Job работает с локальными путями. [Сервис](../app/Services/Comments/AttachmentArchiveService.php) · [Job](../app/Jobs/FillCommentAttachmentArchiveJob.php)
