# Результаты проверки

Выделенный репозиторий имеет собственную историю Git. Сохранённые исходные файлы сверены с рабочей копией исходного проекта по SHA-256. Все четыре исходных тестовых файла совпадают побайтно.

## Локальный запуск

- Версии при проверке на Windows — PHP 8.2.17, Laravel 9.52.20, MySQL 8.0.31 и PHPUnit 9.6.22.
- Все 24 миграции и оба сидера справочников выполнились на отдельной схеме MySQL.
- Docker Compose собрал PHP-образ и запустил приложение, воркер и MySQL. Запрос от синтетического участника проекта с `only=files` получил HTTP 200 и `filling_status: filled`. По возвращённому URL скачался ZIP с файлом `example.txt`.
- PHPUnit запускался на отдельной тестовой схеме. На Windows и в Linux-контейнере получен одинаковый результат — **7 тестов прошли, 1 завершился ошибкой, 22 проверки выполнены**.
- Проверка синтаксиса PHP прошла. PHP 8.2 сообщает об устаревшей сигнатуре исходного метода `AttachmentArchiveService::create`, где необязательный параметр расположен перед обязательным.
- Проверены список файлов коммита и характерные шаблоны секретов. Рабочие `.env`, приватные ключи, токены сервисов, клиентские вложения и экспорт данных в коммит не попали. `docker/mysql-init.sql` подготавливает только локальную тестовую схему.

## Исходные тесты

| Тестовый файл | Что проверяет |
|---|---|
| `AttachmentArchiveServiceTest.php` | Отсутствие вложений, переиспользование готового архива, создание ZIP и запись архива. |
| `GetFilesZipTest.php` | Сценарий отказа проверяет HTTP 401 и 403. Тест успешного запроса использует исходный импорт `APP\Models\ProjectUser`, тогда как Composer сопоставляет префикс `App\`. Если класс ещё не загружен, тест падает до HTTP-запроса. |
| `FillCommentAttachmentArchiveJobTest.php` | Запускает продолжение через очередь в MySQL и проверяет оба файла внутри ZIP. |
| `DeleteOldAttachmentsTest.php` | Удаляет устаревшую запись и её ZIP, сохраняя свежую запись. |

Пробелы в покрытии описаны в [ревью кода](code-review.md).
