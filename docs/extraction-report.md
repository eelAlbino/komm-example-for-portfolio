# Отчёт о выделении модуля

## Исходный код и границы

В репозитории сохранён контур коммерческого приложения, который создаёт и выдаёт ZIP-архивы с вложениями комментариев. В него входят обработчик в `CommentController`, Form Request, политика просмотра, связи дерева комментариев и вложений, сервис и модель архива, Job для сборки, команда очистки, миграции и тесты.

[Перечень исходных файлов](original-files.txt) включает 89 файлов, совпадающих с исходником побайтно. Среди них сервис, модель архива, Job, Form Request, команда очистки и все четыре исходных тестовых файла. У портфолио собственная история Git.

История ветки включает обезличенные изменения файлов ZIP-сервиса, задания, модели архива, запроса, очистки, миграций архива и четырёх наборов тестов. Для 18 исходных коммитов сохранены даты автора и коммитера с часовыми поясами. Сообщения описывают изменения выбранных файлов, имена и адреса авторов заменены. Изменения из соседних модулей и топология слияний исключены. Полное автономное окружение появляется в последнем коммите. Хеши коммитов изменились при переносе.

## Добавлено для локального запуска

- `app/Console/Commands/SeedPortfolioArchive.php` создаёт синтетические данные с помощью исходных фабрик и выдаёт JWT участнику проекта. Команда добавлена при выделении.
- `.env.example`, `Dockerfile`, `compose.yaml` и `docker/mysql-init.sql` настраивают приложение, воркер и две локальные схемы. SQL создаёт тестовую схему и выдаёт права локальному пользователю.
- Правила Git и Docker, файлы для сохранения пустых каталогов и документация добавлены при упаковке.

## Ограничения и проверка перед публикацией

За пределами выделенного модуля остались виджет и административный интерфейс, полные операции с комментариями, снапшоты, уведомления и вебхуки, биллинг, регистрация пользователей, интеграции с трекерами и сгенерированные gRPC-контракты. Локальный запуск показывает работу Eloquent, диска и очереди. Поведение внешних провайдеров и конфигурация промышленного окружения остаются за его пределами.

Владелец подтвердил право раскрыть выбранный код через указанный репозиторий GitHub после исключения конфиденциальной информации. Файлы отбирались по явному списку. В коммит не попали рабочие `.env`, базы и дампы, кэш, конфигурация промышленного окружения, медиа, логи, установленные зависимости и полная история исходного проекта. Учётные данные в Compose предназначены для локальных контейнеров. Фиксированный bcrypt-хеш в исходной фабрике пользователя относится к тестовому паролю Laravel. Команда для демонстрации генерирует случайный пароль отдельно. Ограничения доступа при локальном запуске приведены в [ревью кода](code-review.md).
